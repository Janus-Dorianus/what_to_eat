# 今晚吃什么

## 【介绍】

针对每天晚上出门之后不知道吃什么这个世纪难题，本人使用trae开发了一款用于决定今晚吃什么的软件，软件包括以下内容：
* 1 点击吃什么按钮，随机抽取一个展示，然后该选项七天之内权重降低。
* 2 具备简单的增加条目和删除条目的功能。

## 【使用方法】

### 一、基本使用

* 1、下载index.html文件到本地，使用浏览器打开。
* 2、点击<吃什么>按钮选择，转盘停止后会显示抽取结果。

### 二、增删功能

店家可能会由于激烈的市场竞争导致离开，又会有新的店家迁入。在这里引入了增删功能用于更新选择。

* 1、输入框中输入店家名字，点击添加可以将条目添加到选择中。
* 2、店家后面的 x 号用于删除条目。
